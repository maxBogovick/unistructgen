# 🎥 Video Setup Guide (Professional Standard)

Before recording, ensure your environment looks clean and readable.

## 🖥️ Screen / Resolution
*   **Resolution:** Record at **1920x1080 (1080p)** or **2560x1440 (2k)**. Do not record ultrawide.
*   **Clean Desktop:** Hide desktop icons. Use a solid dark wallpaper or a minimal abstract background.

## 📝 Editor (VS Code / RustRover)
*   **Theme:** Use a high-contrast dark theme.
    *   *Recommendation:* "One Dark Pro", "Dracula", or "GitHub Dark".
*   **Font:** Use a font with ligatures (makes code look professional).
    *   *Recommendation:* "JetBrains Mono", "Fira Code".
    *   **Size:** Set font size to **16px** or **18px**. It must be readable on a smartphone!
*   **Layout:**
    *   Close the file explorer (Ctrl+B / Cmd+B) when writing code to maximize space.
    *   Close the terminal unless running commands.
    *   Hide "Minimap" (it adds noise).

## ⌨️ Terminal
*   **Theme:** Match the editor theme.
*   **Prompt:** Keep it short. Instead of `/Users/maxim/RustroverProjects/unistructgen`, customize prompt to show just `➜ unistructgen`.
*   **Clear:** Always run `clear` before starting a take.

## 🎙️ Audio
*   Pause for 1 second before and after running a command (easier to edit later).
*   Don't type and talk at the same time (keyboard noise).
